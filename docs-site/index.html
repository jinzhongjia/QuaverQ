为什么选 QuaverQ

每个细节都对齐 QQ 音乐 PC 端，原生集成 Linux 桌面环境。

沉浸式同步歌词

超大封面 + 居中歌词，按字着色的卡拉 OK 高亮跟唱效果；无逐字数据时自动回退逐行。

完整播放队列

顺序 / 单曲循环 / 列表循环 / 随机四种模式自由切换；重启即续播，队列、进度、音量全部恢复。

音质自由切换

标准 / 均衡 / 高品质，自动匹配到 MP3 128 / OGG 192 / MP3 320 / FLAC 无损。

原生桌面集成

MPRIS2 媒体键、GNOME 媒体控件、KDE 通知面板原生支持；系统托盘可直接控制播放。

主题跟随系统

浅色 / 深色随桌面切换，也可手动锁定；无边框窗口自绘标题栏，圆角与阴影一致。

秒开冷启动

SWR 缓存策略：上次的首页、歌单、登录态即刻显示，网络在后台静默刷新，首帧零闪动。

常见问题

QuaverQ 是 QQ 音乐官方客户端吗？

不是。QuaverQ 是第三方客户端，与腾讯公司无任何关联。所有版权内容归原版权方所有，本程序不提供任何版权内容下载。

需要登录 QQ 音乐账号吗？

是的，播放歌曲需要先扫码登录。启动后会弹出二维码，使用 QQ 音乐手机端扫码即可。登录凭据保存在 ~/.config/quaverq/，重启自动恢复。

支持 Windows / macOS 吗？

v1 仅支持 Linux。Windows / macOS 在后续规划中，但暂无明确时间表。底层 PySide6 是跨平台的，主要工作量在桌面集成（托盘、MPRIS 等价物、主题）。

数据存在哪里？
  • ~/.config/quaverq/ — 配置、登录凭据、会话快照、设备 ID
  • ~/.cache/quaverq/ — 封面磁盘缓存、首屏快照

封面缓存上限可在设置页配置（128 MB ~ 2 GB / 无限制），支持一键清理。

AppImage 跑不起来怎么办？

先检查依赖：ldd 提示缺什么补什么。绝大多数主流发行版安装好 libEGL1 / libGL1 / libxkbcommon0 / libxcb-* / libpulse0 即可。若仍异常，欢迎邮件反馈到 mail@nvimer.org，附 ldd 输出与启动日志。

项目使用了什么技术栈？

PySide6 + Qt Quick (QML) · QtMultimedia · qasync · dbus-next · curl-cffi · Nuitka（打包）。
